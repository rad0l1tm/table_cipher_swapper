column_swapper.py
=================
Программа, которая переставляет перемешанные столбцы таблицы с текстом таким образом, чтобы получился исходный текст.

Идея
=
В качестве основного алгоритма используется [метод отжига](https://ru.algorithmica.org/cs/combinatorial-optimization/annealing/).
Для корректировки используются собранные из русскоязычного корпуса частотности сочетаний двух, трех и четырех букв (bigrams.txt, trigrams.txt и tetragrams.txt соответственно).

Использование
=
```
python column_swapper.py [-b | --bigrams bigrams.txt] [-t | --trigrams trigams.txt] [-q | --tetragrams tetragrams.txt] [-g | --table <file>] [-i | --iters <value>] [-r | --restars <num>] [-s | --seed <num>]
```
Требования
=
Файл с таблицей содержит текст таким, каким он записан в таблице с пробелами и знаками пунктуации и разделителем табуляцией, пробелом или без разделителя.

Ручной подбор
=
С помощью программы electo.py можно вручную провести подбор порядка столбцов. При этом наличие в таблице разделителей не требуется.
